# Moving in from the browser wall (`wall` namespace, 2026-11-26)

How to open existing `g3d-termd --ns wall` terminals in the native wall (`glyph3d-native` / `Glyph3D Wall.app`) with their browser-wall layout intact.

## Where the browser wall keeps its state

1. **Terminal processes, `cols × rows`, and scrollback** already live in `g3d-termd` under namespace `wall` (`termd-wall.sock`), keyed by `termd` terminal IDs (`t1`, `t2`, …, `gx-<agent>`). No relay owns them; closing the browser tab or stopping the Go relay leaves every terminal running in `g3d-termd`.
2. **Canvas layout and chrome state** (`WallStore.js` in `glyph3d-js/wall/`) live **only in browser `window.localStorage`** — there is no server-side store file and no `wall.export` relay verb. Each browser origin stores 13 JSON-stringified entries per relay port (`glyph3d.wall.relay-<port>.<section>`):
   - `positions`, `names`, `attached`, `hidden`, `groups` (including `split` pane trees), `sidebar`, `status`, `config`, `settings`, `help`, `fullscreen` (including `saved` pre-fullscreen pane `{cols, rows, x, y}`), `fullscreenText`, and `agentViews`.
3. **Coordinate space and IDs match 1:1:** Native `WallStore` (`~/Library/Application Support/glyph3d/wall/wall-<ns>.json` on macOS, `${XDG_STATE_HOME:-~/.local/state}/glyph3d/wall/wall-<ns>.json` on Linux, or `$G3D_TERMD_DIR/wall-<ns>.json` in scratch runs) uses the exact same world coordinate space (`WORLD_CELL_HEIGHT = 2.4`, `PANEL_PAD = 0.3`, `y` up) and the exact same `g3d-termd` terminal IDs.

## Step-by-step migration

### 1. Export the browser wall's `localStorage` from the browser tab

In the browser tab where your JS wall is open, open the DevTools Console (`⌥⌘J` in Chrome / `⌥⌘C` in Safari) and run this one-liner to copy all `glyph3d.wall.*` keys to the clipboard:

```js
copy(JSON.stringify(Object.fromEntries(Object.entries(localStorage).filter(([k]) => k.startsWith('glyph3d.wall.'))), null, 2))
```

Save the clipboard to a file in a terminal:

```sh
pbpaste > ~/Downloads/wall-browser.json
```

*(Linux / non-macOS alternative: if `pbpaste` is unavailable, run this in the browser DevTools Console to download `wall-browser.json` directly:)*

```js
Object.assign(document.createElement('a'), { href: URL.createObjectURL(new Blob([JSON.stringify(Object.fromEntries(Object.entries(localStorage).filter(([k]) => k.startsWith('glyph3d.wall.'))), null, 2)], { type: 'application/json' })), download: 'wall-browser.json' }).click()
```

Close (or disconnect) the browser wall tab so it no longer owns terminal resize events on namespace `wall`.

### 2. Import into the native `wall` namespace store

Run `wallctl` targeting `--ns wall` **before** (or while) opening the native wall:

```sh
./target/release/wallctl --ns wall wall.import ~/Downloads/wall-browser.json
```

*(If you built `Glyph3D Wall.app` via `tools/wall-bundle.sh`, `wallctl` is also bundled at `target/bundle/Glyph3D Wall.app/Contents/MacOS/wallctl`.)*

- **When no native window is open on `wall` yet (recommended):** `wallctl` writes `~/Library/Application Support/glyph3d/wall/wall-wall.json` directly and prints a full summary of mapped counts and any unmapped items.
- **When a native window is already open on `wall`:** `wallctl` sends `wall.import` over `wall-wall.sock`; the running window writes `wall-wall.json`, reloads its `Wall` model over the live `Sessions`, applies dialled font/text/grid knobs, frames the canvas, and replies with the same summary.
- **Multiple `relay-<port>` scopes in one browser profile:** If you previously opened walls on more than one relay port and only one scope is non-empty, the importer selects it automatically. If multiple scopes hold non-empty layouts, `wallctl` lists them with item counts so you can name the port explicitly:

  ```sh
  ./target/release/wallctl --ns wall wall.import ~/Downloads/wall-browser.json relay-8765
  ```

### 3. Open the native wall on namespace `wall`

From the command line:

```sh
./target/release/glyph3d-native --wall-ns wall
```

Or through the macOS app bundle:

```sh
open "target/bundle/Glyph3D Wall.app" --args --wall-ns wall
```

*(A bare launch with no `--wall-ns` flag opens namespace `rs-wall`, leaving `wall` separate until `--wall-ns wall` is passed or imported into `rs-wall`.)*

## What maps and what does not

| Browser state | Native mapping |
|---|---|
| `positions` (`{x, y}` world units) | **Maps 1:1** — identical world cell scale (`2.4` tall, `0.3` pad, `y` up). Dead terminals no longer in `g3d-termd` are pruned automatically on connect. |
| `names`, `attached` (`name[@host]`), `hidden` | **Maps 1:1** — custom titles, `gomuxai` attachments, and hidden flags carry over unchanged. |
| `groups` (`tile`, `freeform`, `split` + binary `SplitNode` ratios & `bars`) | **Maps 1:1** — split trees are validated against `members` (a corrupt split downgrades cleanly to `tile` and is listed under `unmapped`). |
| Terminal `cols × rows` & scrollback | **Adopted live from `g3d-termd`** on connect (`Sessions::adopt`); split pane proportions come from `groups[gid].split`, and pre-fullscreen sizes come from `fullscreen.saved`. |
| `sidebar`, `status`, `settings`, `help` (`open`, `side`, `float`, `collapsed`) | **Maps 1:1** — docked (`left`/`right`) and floating (`{x, y}`) panel placements and folded sections carry over. |
| `fullscreen` & `fullscreenText` | **Maps 1:1** — active single/group fullscreen state, saved pre-fullscreen canvas geometries, and per-terminal fullscreen row heights (`linePx`) carry over. |
| `agentViews` (`open`, `side`, `session`, `filters`) | **Maps 1:1** — paired `gomuxai` transcript companions and category filters reopen beside their terminals. |
| `config` overrides (`fontFamily`, `snap`, `grid*`, `selection*`, `optionAsAlt`, `lineThickness`, …) | **Validated per knob** against `wall_core::config::check_config` (`cousine`, `monaspace-neon`, `monaspace-argon`, plus native `fontSize` / `lineHeight` and installed system fonts). |
| `config.renderLoop = "always"` | **Unmapped (reported)** — the native wall always sleeps on `ControlFlow::Wait` when idle and has no continuous-spin mode. |
| `config.traceInput = true` | **Unmapped (reported)** — logged browser events to the Go relay's log store; the native wall has no Go relay. |
| `glyph3d.relay.*` (`localStorage` capability tokens) | **Unmapped (reported)** — browser WebSocket relay auth tokens; the native wall connects directly to `g3d-termd`'s `0600` Unix socket. |
| Ephemeral tab state (camera pan/zoom outside fullscreen, focus history, active text/lasso selection, expanded Agent View cards) | **Not persisted in `WallStore`** in either browser or native wall — opening frames all shown terminals with `wall.fit`. |
